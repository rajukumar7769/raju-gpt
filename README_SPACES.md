# RAJU-GPT

AI Chatbot with RAG (Retrieval Augmented Generation) using TinyLlama-1.1B model.

## Features
- Local LLM with web search capabilities
- User authentication
- Chat history
- Voice input
- Dark/Light mode

## Usage

Visit the app URL and:
1. Register an account
2. Login with your credentials
3. Start chatting with RAJU-GPT

The chatbot uses real-time web search to provide accurate, up-to-date responses.

## Tech Stack
- Django 4.2
- TinyLlama-1.1B-Chat
- SerpAPI for web search
- PyTorch & Transformers
